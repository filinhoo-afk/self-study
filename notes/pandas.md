## NumPy

```python
import numpy as np
a = np.array([1, 2, 3])
```

| | список `[1, 2, 3]` | массив `np.array([1, 2, 3])` |
|---|---|---|
| `* 2` | повторение: `[1, 2, 3, 1, 2, 3]` | к каждому элементу: `[2, 4, 6]` |

Операция сразу над всеми элементами, без цикла, — **векторизация**. Быстро, потому что внутри код на C.

⚠ Матрицы в коде пишутся **по строкам**: `[[0, -1], [1, 0]]` — две строки. Геометрический смысл (куда попали i и j) читается **по столбцам**.

## pandas: основы

```python
import pandas as pd
```

### Два главных объекта

| | `Series` | `DataFrame` |
|---|---|---|
| что это | один столбец | таблица |
| индекс | есть | общий для всех столбцов |
| имя | `name=` — одно имя | у каждого столбца своё название |

DataFrame = несколько Series рядом с общим индексом.

### Создать DataFrame

```python
pd.DataFrame({'Столбец1': [знач, знач], 'Столбец2': [знач, знач]})
pd.DataFrame({...}, index=['строка A', 'строка B'])
```

- Словарь описывает таблицу **по столбцам**: ключ → название столбца, список → значения сверху вниз.
- Все списки **одной длины** (= число строк).
- Без `index=` строки нумеруются с 0.

### Создать Series

```python
pd.Series([знач, знач, знач])
pd.Series([знач, знач, знач], index=['a', 'b', 'c'], name='Имя')
```

- Значения — **список**, а не словарь (словарь — это формат DataFrame; если передать словарь в Series, его ключи станут индексом).
- Длина `index` = число значений.

### Чтение и запись файлов

```python
df = pd.read_csv("путь/к/файлу.csv")
df = pd.read_csv("путь/к/файлу.csv", index_col=0)   # первый столбец файла — индекс
df.to_csv("имя.csv")                                # сохранить в CSV
```

- Путь — **строка, в кавычках**. Без кавычек — `SyntaxError`.
- Если в результате появился столбец `Unnamed: 0` с номерами строк — в файле уже был индекс → нужен `index_col=0`.
- Признак такого файла: первая строка CSV начинается с запятой (у первого столбца нет названия).

### Осмотреться в данных

| команда | что даёт |
|---|---|
| `df.shape` | размер: `(строк, столбцов)` — без скобок, это не функция |
| `df.head()` | первые 5 строк |
| `df.head(10)` | первые 10 строк |

### Выбор данных (Kaggle, урок 2)

| что нужно | как | результат |
|---|---|---|
| один столбец | `df['col']` или `df.col` | Series |
| столбец с пробелом/скобками в имени | только `df['Price(euro)']` | Series |
| несколько столбцов | `df[['col1', 'col2']]` — двойные скобки: список внутри | DataFrame |
| элемент столбца | `df['col'][0]` | значение |
| по **номеру** позиции | `df.iloc[строки, столбцы]` | |
| по **названию** (метке) | `df.loc[строки, столбцы]` | |

```python
df.iloc[0]            # первая строка
df.iloc[:, 0]         # все строки, первый столбец (":" — «всё»)
df.iloc[1:3, 0]       # строки 1, 2
df.iloc[[0, 2], 0]    # строки 0 и 2
df.iloc[-5:]          # последние 5 строк
df.loc[0, 'country']  # ячейка по меткам
df.loc[:, ['country', 'points']]
df.set_index('title') # сделать столбец индексом
```

⚠ **Граница среза:** `iloc[0:3]` → строки 0, 1, 2 (как в Python, не включая). `loc[0:3]` → 0, 1, 2, **3** (включительно — потому что метки бывают и словами).

### Выбор строк по условию

```python
df['country'] == 'Italy'                    # Series из True/False — по одному на строку
df.loc[df['country'] == 'Italy']            # только строки с True
df.loc[(df['country'] == 'Italy') & (df['points'] >= 90)]   # И
df.loc[(df['country'] == 'Italy') | (df['points'] >= 90)]   # ИЛИ
df.loc[~(df['Year'] < 1970)]                # НЕ
df.loc[df['country'].isin(['Italy', 'France'])]   # значение из списка
df.loc[df['price'].notnull()]               # где нет пропуска
df.loc[df['price'].isnull()]                # где пропуск (NaN)
```

⚠ В pandas не `and` / `or` / `not`, а `&` / `|` / `~`, и **каждое условие в скобках**.

### Запись данных

```python
df['new_col'] = 'значение'          # одно значение во все строки
df['new_col'] = range(len(df), 0, -1)   # последовательность
df['Age'] = df['Year'].max() + 1 - df['Year']   # из других столбцов
```

Если столбец уже есть — перезапишется (`=` заменяет).

### Сводные функции (Kaggle, урок 3)

| команда | что даёт |
|---|---|
| `s.describe()` | count, mean, std, min, 25%, 50%, 75%, max (для чисел) |
| `s.mean()`, `s.median()`, `s.max()`, `s.min()` | одно число |
| `s.unique()` | список уникальных значений |
| `s.nunique()` | сколько уникальных |
| `s.value_counts()` | сколько раз встречается каждое значение, **по убыванию** |
| `s.mode()` | самое частое значение — **Series**, при равенстве частот вернёт несколько, поэтому `s.mode()[0]` |

```python
s.value_counts()['blue']      # метка индекса, а не позиция
counts = df['Model'].value_counts()
freqs = counts / counts.sum() # доли от 0 до 1 (поэлементное деление)
rare = counts[freqs <= 0.001] # маска True/False по долям
```

⚠ `Series / число` и `Series * число` работают **поэлементно** (как `np.array`, не как `list`).

### map, replace, apply

```python
s.map({'red': 'красный'})        # нет ключа → NaN!
s.replace({'red': 'красный'})    # нет ключа → остаётся как было
df['Model'].replace(rare.index.values, 'Rare')   # список названий → одно значение
df['x'].apply(func)              # func БЕЗ скобок, вызывается для каждого значения
df.apply(func, axis=1)           # по строкам: func получает row, значения — row['Make']
```

- `rare.index.values` — названия (метки), а не числа из `rare`.
- В `apply` передаём саму функцию (`func`), а не результат вызова (`func(5)`).
- Функция должна **возвращать** (`return`), а не печатать: иначе в столбце будет `None`.

### groupby и пустые выборки

```python
df.groupby(['Make', 'Model', 'Year'])['Style'].nunique()   # сколько разных Style в каждой комбинации
df.groupby([...])['Style'].nunique().value_counts()        # у скольких комбинаций 1, 2, 3… стиля
```

Идея: `groupby` собирает строки с одинаковым ключом в группы (как словарь «ключ → набор значений» в цикле), потом считает по каждой группе.

```python
sel = data[(data['Make'] == make) & (data['Model'] == model)]
sel.shape[0] == 0     # пустая выборка: DataFrame с колонками, но без строк (не ошибка и не None)
sel['Style'].mode()[0]    # на пустой выборке даст ошибку → сначала проверить shape[0]
```

### Числовые колонки и сохранение

```python
df.select_dtypes(include='number')   # только числовые (bool сюда НЕ входит)
df.to_csv('file.csv', index=False)   # index=False — без лишнего столбца индекса
df.reset_index(drop=True)            # заново пронумеровать с 0, старый индекс выбросить
df.drop_duplicates()                 # убрать повторяющиеся строки
```

### Что значат обозначения в выводе

| в выводе | значит |
|---|---|
| `NaN` | пропущенное значение (Not a Number) — в реальных данных бывает почти всегда |
| `dtype: int64` | целые числа |
| `dtype: float64` | дробные числа (и целые, если в столбце есть `NaN`) |
| `dtype: object` | обычно строки (текст) |
| `Unnamed: 0` | столбец без названия в файле — часто лишний индекс |
| `...` в середине таблицы | pandas скрыл часть строк при выводе, данные на месте |
