## NumPy

```python
import numpy as np
a = np.array([1, 2, 3])
```

| | список `[1, 2, 3]` | массив `np.array([1, 2, 3])` |
|---|---|---|
| `* 2` | повторение: `[1, 2, 3, 1, 2, 3]` | к каждому элементу: `[2, 4, 6]` |

Операция сразу над всеми элементами, без цикла, — **векторизация**. Быстро, потому что внутри код на C.

⚠ Матрицы в коде пишутся **по строкам**: `[[0, -1], [1, 0]]` — две строки. Геометрический смысл (куда попали i и j) читается **по столбцам**.

## pandas: основы

```python
import pandas as pd
```

### Два главных объекта

| | `Series` | `DataFrame` |
|---|---|---|
| что это | один столбец | таблица |
| индекс | есть | общий для всех столбцов |
| имя | `name=` — одно имя | у каждого столбца своё название |

DataFrame = несколько Series рядом с общим индексом.

### Создать DataFrame

```python
pd.DataFrame({'Столбец1': [знач, знач], 'Столбец2': [знач, знач]})
pd.DataFrame({...}, index=['строка A', 'строка B'])
```

- Словарь описывает таблицу **по столбцам**: ключ → название столбца, список → значения сверху вниз.
- Все списки **одной длины** (= число строк).
- Без `index=` строки нумеруются с 0.

### Создать Series

```python
pd.Series([знач, знач, знач])
pd.Series([знач, знач, знач], index=['a', 'b', 'c'], name='Имя')
```

- Значения — **список**, а не словарь (словарь — это формат DataFrame; если передать словарь в Series, его ключи станут индексом).
- Длина `index` = число значений.

### Чтение и запись файлов

```python
df = pd.read_csv("путь/к/файлу.csv")
df = pd.read_csv("путь/к/файлу.csv", index_col=0)   # первый столбец файла — индекс
```

- Путь — **строка, в кавычках**. Без кавычек — `SyntaxError`.
- Если в результате появился столбец `Unnamed: 0` с номерами строк — в файле уже был индекс → нужен `index_col=0`.

### Выбор данных (Kaggle, урок 2)

| что нужно | как | результат |
|---|---|---|
| один столбец | `df['col']` или `df.col` | Series |
| столбец с пробелом/скобками в имени | только `df['Price(euro)']` | Series |
| несколько столбцов | `df[['col1', 'col2']]` — двойные скобки: список внутри | DataFrame |
| элемент столбца | `df['col'][0]` | значение |
| по **номеру** позиции | `df.iloc[строки, столбцы]` | |
| по **названию** (метке) | `df.loc[строки, столбцы]` | |

```python
df.iloc[0]            # первая строка
df.iloc[:, 0]         # все строки, первый столбец (":" — «всё»)
df.iloc[1:3, 0]       # строки 1, 2
df.iloc[[0, 2], 0]    # строки 0 и 2
df.iloc[-5:]          # последние 5 строк
df.loc[0, 'country']  # ячейка по меткам
df.loc[:, ['country', 'points']]
df.set_index('title') # сделать столбец индексом
```

⚠ **Граница среза:** `iloc[0:3]` → строки 0, 1, 2 (как в Python, не включая). `loc[0:3]` → 0, 1, 2, **3** (включительно — потому что метки бывают и словами).

### Выбор строк по условию

```python
df['country'] == 'Italy'                    # Series из True/False — по одному на строку
df.loc[df['country'] == 'Italy']            # только строки с True
df.loc[(df['country'] == 'Italy') & (df['points'] >= 90)]   # И
df.loc[(df['country'] == 'Italy') | (df['points'] >= 90)]   # ИЛИ
df.loc[~(df['Year'] < 1970)]                # НЕ
df.loc[df['country'].isin(['Italy', 'France'])]   # значение из списка
df.loc[df['price'].notnull()]               # где нет пропуска
df.loc[df['price'].isnull()]                # где пропуск (NaN)
```

⚠ В pandas не `and` / `or` / `not`, а `&` / `|` / `~`, и **каждое условие в скобках**.

```python
df['new_col'] = 'значение'          # одно значение во все строки
df['new_col'] = range(len(df), 0, -1)   # последовательность
df['Age'] = df['Year'].max() + 1 - df['Year']   # из других столбцов
```

Если столбец уже есть — перезапишется (`=` заменяет).

### Сводные функции (Kaggle, урок 3)

| команда | что даёт |
|---|---|
| `s.describe()` | count, mean, std, min, 25%, 50%, 75%, max (для чисел) |
| `s.mean()`, `s.median()`, `s.max()`, `s.min()` | одно число |
| `s.unique()` | список уникальных значений |
| `s.nunique()` | сколько уникальных |
| `s.value_counts()` | сколько раз встречается каждое значение, **по убыванию** |
| `s.mode()` | самое частое значение — **Series**, при равенстве частот вернёт несколько, поэтому `s.mode()[0]` |

```python
s.value_counts()['blue']      # метка индекса, а не позиция
counts = df['Model'].value_counts()
freqs = counts / counts.sum() # доли от 0 до 1 (поэлементное деление)
rare = counts[freqs <= 0.001] # маска True/False по долям
```

⚠ `Series / число` и `Series * число` работают **поэлементно** (как `np.array`, не как `list`).

### map, replace, apply

```python
s.map({'red': 'красный'})        # нет ключа → NaN!
s.replace({'red': 'красный'})    # нет ключа → остаётся как было
df['Model'].replace(rare.index.values, 'Rare')   # список названий → одно значение
df['x'].apply(func)              # func БЕЗ скобок, вызывается для каждого значения
df.apply(func, axis=1)           # по строкам: func получает row, значения — row['Make']
```

- `rare.index.values` — названия (метки), а не числа из `rare`.
- В `apply` передаём саму функцию (`func`), а не результат вызова (`func(5)`).
- Функция должна **возвращать** (`return`), а не печатать: иначе в столбце будет `None`.

### groupby и пустые выборки

```python
df.groupby(['Make', 'Model', 'Year'])['Style'].nunique()   # сколько разных Style в каждой комбинации
df.groupby([...])['Style'].nunique().value_counts()        # у скольких комбинаций 1, 2, 3… стиля
```

Идея: `groupby` собирает строки с одинаковым ключом в группы (как словарь «ключ → набор значений» в цикле), потом считает по каждой группе.

```python
sel = data[(data['Make'] == make) & (data['Model'] == model)]
sel.empty             # пустая выборка: DataFrame с колонками, но без строк (не ошибка и не None)
modes = sel['Style'].mode()
modes.iloc[0]         # на пустом результате mode() даст IndexError → сначала проверить modes.empty
```

- `.empty` (без скобок) читается лучше, чем `shape[0] == 0`; `shape[0]` — число строк.
- Пустой результат при «ничего нет»: `np.nan` (а не строка `'нет данных'`): `Series.mean()` и др. в pandas тоже дают `nan` на пустом, а строка ломает арифметику (`TypeError`). `nan` расползается молча — писать в комментарии; проверять через `pd.isna(x)`, не `x == nan`.
- `mode()` возвращает **все** значения с максимальной частотой по возрастанию (`iloc[0]` при равенстве — наименьшее). `dropna=True` по умолчанию: `NaN` в моде не учитываются, даже если их больше всех; все `NaN` → пустой `Series`.
- `.value_counts()['Rare']` упадёт с `KeyError`, если метки нет; безопаснее `(df['Model'] == 'Rare').sum() / len(df)`.

### groupby (Kaggle, урок 4)

Идея: **разделить на группы → посчитать по каждой → собрать**. Строк в результате столько, сколько групп.

```python
df.groupby('brand')['price'].mean()           # Series: индекс — группы
df.groupby('brand').size()                    # сколько строк в каждой группе
df.groupby(['brand', 'year'])['price'].mean() # две колонки → MultiIndex (два уровня индекса)
df.groupby('brand')['price'].agg(['min', 'max', 'mean'])   # несколько функций, названия в кавычках
df.groupby('brand')['price'].mean().reset_index().sort_values('price', ascending=False)
```

| | `groupby(...)` | `value_counts()` |
|---|---|---|
| что умеет | любое вычисление по группам (mean, max, sum, size, agg, apply) | только считает, сколько раз встречается каждое значение |
| порядок | по ключу группы (текст — по алфавиту) | по убыванию частоты |

`value_counts()` ≈ `groupby(col).size()` + сортировка по убыванию.

- `reset_index()` переносит уровни индекса в обычные столбцы (после `groupby` по двум колонкам удобно для фильтра и сортировки).
- `reset_index(drop=True)` выбрасывает старый индекс; без `drop=True` он станет лишним столбцом `index` (после `sort_values` там будут перемешанные старые номера).
- `agg(['min', 'max'])` — без кавычек `min`/`max` даёт FutureWarning.
- `df['a']` → `Series`, `df[['a']]` → `DataFrame` (список столбцов, даже из одного).

### Сортировка

```python
df.sort_values('price')                          # по возрастанию
df.sort_values('price', ascending=False)         # по убыванию
df.sort_values(['brand', 'price'])               # сначала по brand, внутри — по price
df.sort_index()                                  # по индексу
```

После сортировки индекс сохраняет старые номера строк (1, 0, …) — при необходимости `reset_index(drop=True)`.

```python
df.select_dtypes(include='number')   # только числовые (bool сюда НЕ входит)
df.to_csv('file.csv', index=False)   # index=False — без лишнего столбца индекса
df.reset_index(drop=True)            # заново пронумеровать с 0, старый индекс выбросить

```

### Что значат обозначения в выводе

| в выводе | значит |
|---|---|
| `NaN` | пропущенное значение (Not a Number) — в реальных данных бывает почти всегда |
| `dtype: int64` | целые числа |
| `dtype: float64` | дробные числа (и целые, если в столбце есть `NaN`) |
| `dtype: object` | обычно строки (текст) |
| `Unnamed: 0` | столбец без названия в файле — часто лишний индекс |

### Series со словами и длинами (хендбук 6.2, задачи A и E)

```python
words = sorted(set(clean.split()))                    # уникальные слова по алфавиту
lengths = [len(w) for w in words]                     # или циклом с append
s = pd.Series(lengths, index=words, dtype='int64')    # значения — длины, индекс — слова

def get_long(data, min_length=5):
    return data[data >= min_length]                   # маска по значениям Series
```

- **Series из двух списков:** значения — первым аргументом, метки — в `index=`; порядок значений и меток должен совпадать.
- **Очистка текста:** `.lower()`, символ за символом `char.isalpha() or char.isspace()` оставляет только буквы и пробелы (цифры и знаки препинания уходят); `.split()` без аргумента делит по любым пробелам и не даёт пустых слов.
- **Уникальные и отсортированные:** `set` убирает повторы, но порядок теряет → `sorted(set(...))`.
- **Фильтр Series по значению:** `data[data >= n]` — то же, что маска в DataFrame, но без `loc`; индекс (слова) у отобранных элементов сохраняется.
- `dtype='int64'` указывать полезно, если проверка сравнивает тип; на пустом списке без него был бы `object`.
- Аргумент по умолчанию (`min_length=5`) используется, если при вызове число не передали.

## Подготовка признаков для моделей (пара 07: категории, лес, линейная регрессия)

### Разбиение данных — до любой обработки

```python
from sklearn.model_selection import train_test_split

y = df['Price']                                  # что предсказываем (цель)
X = df.drop(columns=['Price', 'Age'])            # признаки; Age дублирует Year
X_train, X_hold, y_train, y_hold = train_test_split(X, y, test_size=0.4, random_state=42)
X_valid, X_test, y_valid, y_test = train_test_split(X_hold, y_hold, test_size=0.5, random_state=43)
```

| часть | доля | зачем |
|---|---|---|
| train | 60 % | учить модель, строить словари кодов и доли категорий |
| valid | 20 % | сравнивать варианты: порог, набор признаков, способ кодирования |
| test | 20 % | один раз в конце — итоговая оценка; по нему ничего не подбирают |

- ⚠ **Утечка данных:** всё, что «учится» (словари кодов, доли категорий, средние цены), считают **только по train**, потом применяют к valid и test. Иначе проверка заранее видит ответы, и ошибка выглядит лучше, чем будет на новых данных.
- `random_state=` фиксирует случайность: разбиение повторяется при каждом запуске.

### Типы столбцов

```python
num_cols = X_train.select_dtypes(include='number').columns.tolist()
cat_cols = X_train.select_dtypes(include=['object', 'string', 'category']).columns.tolist()
X_train['AutoTransmission'].map({True: 1, False: 0})   # bool → 0/1, один словарь для всех частей
```

`bool` не входит ни в `number`, ни в `object` — его кодируют отдельно.

### Три способа превратить текст в числа

| способ | как | столбцов | кому подходит |
|---|---|---|---|
| целые коды | словарь `{название: номер}` по train | столько же | дереву и лесу: режут порогами `код <= 5` |
| One-Hot (OHE) | свой столбец 0/1 на каждую категорию | много (9 → 768) | линейной регрессии |
| Target Encoding | категория → сглаженная средняя цена по train | столько же | линейной регрессии; столбцов меньше, но не обязательно точнее |

⚠ Целые коды и линейная регрессия: один коэффициент на столбец → модель считает, что шаг от кода 1 к 2 «стоит» столько же евро, сколько от 2 к 3. У названий марок такого порядка нет. Для леса порядок кодов произвольный, но дерево может отрезать отдельные коды порогами.

**Целые коды:**

```python
codes = {name: i for i, name in enumerate(sorted(train[col].unique()))}   # только по train
other[col].map(codes).fillna(-1).astype(int)
```

- Категории, которой не было в train, нет в словаре → `map` даёт `NaN` (см. «map, replace, apply») → `fillna(-1)` — общий код «неизвестно».
- `astype(int)`: из-за `NaN` столбец стал `float64`, возвращаем целые.

**One-Hot:**

```python
train_ohe = pd.get_dummies(X_train, columns=cat_cols, dtype=int)
valid_ohe = pd.get_dummies(X_valid, columns=cat_cols, dtype=int)
valid_ohe = valid_ohe.reindex(columns=train_ohe.columns, fill_value=0)
```

- `get_dummies` на разных частях даёт **разные наборы столбцов**: в valid может не оказаться какой-то марки или найтись новая. `reindex(columns=...)` выравнивает по train: недостающие столбцы заполняются 0, лишние (новые категории) отбрасываются.
- `dtype=int` — иначе столбцы будут `True`/`False`.
- Минус: у редкой категории свой коэффициент, оценённый по нескольким строкам, — он неустойчив.

**Редкие категории:** доля каждой по train (`value_counts(normalize=True)`) → у кого доля `< порога`, тем общий код (`-1` или `'Rare'`). Категорий становится меньше, но на этих данных MAE при любом пороге **росла** — склейка не помогает автоматически, её проверяют на valid.

**Target Encoding** (sklearn `TargetEncoder(target_type='continuous', cv=5)`): на train `fit_transform(X_train, y_train)`, на valid и test только `transform`. `cv=5` — для строк train средняя цена считается по *другим* частям train, чтобы собственная цена строки не попала в её же признак.

### Модели sklearn: общий шаблон

```python
model = RandomForestRegressor(n_estimators=80, max_depth=16, random_state=42)
model.fit(X_train, y_train)      # учим только на train
pred = model.predict(X_valid)    # прогноз на проверочной части
```

| модель | идея |
|---|---|
| `LinearRegression` | одна формула: свободный член + коэффициент × каждый столбец |
| `DecisionTreeRegressor` | цепочка вопросов `признак <= порог`; `max_depth=3` — чтобы дерево можно было прочитать (`plot_tree`) |
| `RandomForestRegressor` | много деревьев, прогнозы усредняются |
| `CatBoostRegressor`, `LGBMRegressor` | бустинг; CatBoost сам принимает текстовые столбцы через `cat_features=` |

`model.feature_importances_` (у леса) — насколько признак помогал уменьшать ошибку в разбиениях. Это не «процент влияния на цену» и не коэффициент формулы.

### Метрики регрессии

```python
from sklearn.metrics import mean_absolute_error, root_mean_squared_error
mean_absolute_error(y_valid, pred)   # порядок: (факт, прогноз)
```

| | что считает | единицы | особенность |
|---|---|---|---|
| MAE | среднее \|факт − прогноз\| | евро | «типичный промах» |
| RMSE | корень из среднего квадрата ошибки | евро | крупные промахи весят сильнее |

MAE у двух моделей похожа, а RMSE у одной сильно больше → типичный промах одинаковый, но у неё бывают редкие очень большие ошибки.

### Логарифм цели

- У цены длинный правый хвост (несколько очень дорогих машин). Учат на `np.log(y_train)`, прогноз перед подсчётом MAE/RMSE возвращают в евро: `np.exp(pred)`. Линейной регрессии на этих данных это снизило MAE примерно на 1000 €.

`pivot` только перекладывает значения (строки → столбцы) и ничего не считает; если для пары «индекс + столбец» значений несколько — ошибка, тогда нужен `groupby` или `pivot_table`.
