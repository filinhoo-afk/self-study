# 🎯 Угадай число

## Описание

Это игра на Python, в которой компьютер загадывает случайное число, а игрок должен его угадать.

## Как запустить

Открой терминал в папке проекта и введи:

```bash
python guess_number.py
```

Для запуска нужен Python 3.

## Правила игры

1. Выбери, хочешь ли ты играть.
2. Выбери уровень сложности.
3. Вводи числа, чтобы угадать загаданное.
4. Программа подсказывает, больше или меньше загаданное число.
5. Также есть подсказки «горячо» и «холодно».
6. Если число угадано за отведённые попытки — ты победил!
7. После игры можно сыграть ещё раз.
8. Неправильный ввод не тратит попытку.

## Уровни сложности

- **Лёгкий:** число от 0 до 50, 10 попыток.
- **Средний:** число от 0 до 100, 7 попыток.
- **Сложный:** число от 0 до 200, 8 попыток.

На лёгком уровне 10 попыток — это запас для новичка. При правильном выборе середины диапазона хватило бы 6 попыток, поэтому остаётся несколько дополнительных попыток.

## Почему 7 и 8 попыток?

Если каждый раз выбирать число посередине диапазона, подсказка «больше» или «меньше» помогает отбросить примерно половину вариантов.

- Для диапазона 0–50 есть 51 число. Нужно 6 попыток, потому что 2^6 = 64.
- Для диапазона 0–100 есть 101 число. Нужно 7 попыток, потому что 2^7 = 128.
- Для диапазона 0–200 есть 201 число. Нужно 8 попыток, потому что 2^8 = 256.

Этот способ называется **бинарным поиском**. Чем больше диапазон, тем медленнее растёт нужное количество попыток.

В моей игре игрок выбирает числа сам, поэтому для гарантированной победы ему нужно самостоятельно выбирать середину оставшегося диапазона.

## Что использовал

- `random.randint()` — для случайного числа.
- `while` — для повторения игры и попыток.
- `if / elif / else` — для проверок.
- `try / except` — для обработки неправильного ввода.
- Функции — для разделения кода на части.
