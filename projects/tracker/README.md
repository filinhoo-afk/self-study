# Консольный трекер задач

Простая программа для записи дел в консоли. Работает в цикле с меню, пока не выберешь «Выход».

## Запуск

```bash
python projects/tracker/tracker.py
```

Нужен Python 3. Сторонние библиотеки не требуются.

## Меню

1. **Добавить** — вводишь текст задачи, она добавляется в конец списка.
2. **Показать всё** — выводит задачи с номерами, начиная с 1. Если список пуст, сообщает об этом.
3. **Удалить** — показывает список и просит номер задачи для удаления. Если ввести не число или номер вне списка, спросит снова.
4. **Выход** — завершает программу.

Если в меню ввести букву или число вне диапазона 1–4, программа покажет подсказку и снова выведет меню.

## Ограничения

- Задачи хранятся только в памяти (в списке) и пропадают после выхода из программы.
- Нельзя редактировать задачу или отметить её выполненной, только добавить и удалить.
