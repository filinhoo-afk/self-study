# План самообучения: путь к ML-инженеру

## Принципы

- **Регулярность важнее объёма.** ≈2 ч в будни + 4–5 ч в один выходной, один день полностью свободен. В сессию — минимум.
- **Правило 70/30.** Не больше 30% времени на курсы и видео, остальное — задачи и свои проекты.
- **Всё в GitHub.** Это будущее портфолио.
- **ИИ — репетитор, а не исполнитель.** Объясни, проверь, найди ошибку — но код пишу сам.
- **Учёба в приоритете.** Матан, алгебра и дискретка — это и есть математика для ML.
- Примерное распределение недели: ~6 ч программирование и алгоритмы, ~4 ч математика, ~5–6 ч ML и проекты (пропорции меняются по этапам).

## Этап 1. Фундамент программиста (октябрь – декабрь 2026)

Цель: из «знаю синтаксис» стать человеком, который уверенно пишет программы.

- [ ] **Python глубже синтаксиса:** функции, ООП, исключения, файлы, модули, виртуальные окружения, типизация. Ресурсы: «Поколение Python» на Stepik (базовый и для продвинутых), хендбук Яндекса по Python.
- [ ] **Алгоритмы:** 3–5 задач в неделю на LeetCode или Яндекс Контесте (тренировки по алгоритмам).
- [ ] **Инструменты:** Git (ветки, коммиты, pull request), командная строка Linux, VS Code. По возможности — WSL.
- [ ] **Математика:** хорошо сдать матан, алгебру, дискретку. Для интуиции — «Сущность линейной алгебры» (3Blue1Brown).

**Результат:** 2–3 небольших проекта на GitHub (Telegram-бот, парсер, консольная игра) и 30–50 решённых задач.

## Этап 2. Данные и статистика (январь – апрель 2027)

Цель: научиться работать с данными — общая база для ML и аналитики.

- [ ] **NumPy, pandas, matplotlib, seaborn** на реальных датасетах с Kaggle.
- [ ] **SQL:** запросы, JOIN, группировки, оконные функции. Тренажёры: sql-ex.ru, SQL-академия, LeetCode Database.
- [ ] **Теория вероятностей и статистика:** распределения, матожидание, дисперсия, доверительные интервалы, проверка гипотез, A/B-тесты.
- [ ] **Проба аналитики:** полноценное исследование датасета с выводами «для бизнеса».

**Результат:** 2 аналитических проекта (ноутбуки с понятными выводами), уверенный SQL.

## Этап 3. Классическое машинное обучение (май – август 2027)

Цель: понимать, как работают модели, и уметь их применять.

- [ ] **Теория ML:** линейная и логистическая регрессия, деревья, случайный лес, градиентный бустинг, кросс-валидация, метрики, переобучение. Ресурсы: хендбук Яндекса по ML, mlcourse.ai (ODS).
- [ ] **Практика:** scikit-learn, CatBoost / LightGBM, 1–2 соревнования на Kaggle (ради опыта).
- [ ] **Проба ML-инженерии:** модель → API на FastAPI → Docker → деплой, доступ по ссылке. Ключевой проект года.

**Результат:** понимание основных алгоритмов ML, проект «модель в продакшене».

## Второй курс (2027/28): глубокое обучение и бэкенд

- [ ] **Осень:** PyTorch, полносвязные и свёрточные сети, трансформеры. Ресурсы: Deep Learning School (МФТИ), Андрей Карпатый «Neural Networks: Zero to Hero».
- [ ] **Инженерия:** PostgreSQL, REST API, асинхронность, pytest, основы архитектуры сервисов.
- [ ] **Весна:** MLOps — MLflow, пайплайны данных, CI/CD. Книга: Chip Huyen «Designing Machine Learning Systems».
- [ ] **Серьёзный проект:** сервис с нейросетью (рекомендации / классификация изображений / чат-бот на своих данных) с архитектурой, тестами и деплоем.
- [ ] **Весна:** заявки на летние стажировки (Яндекс, Т-Банк, Сбер, VK, Ozon, Авито).

## Третий и четвёртый курс: специализация и работа

- Выбор ниши: LLM и RAG, компьютерное зрение, рекомендательные системы или MLOps.
- Поступление в ШАД (Школа анализа данных Яндекса).
- 3 курс: стажировка или частичная занятость. 4 курс: junior ML-инженер, диплом на рабочей задаче.

## Контрольные точки

- [ ] **Лето 2027:** уверенный Python, 100+ алгоритмических задач, SQL, 3–4 проекта на GitHub, включая задеплоенную модель.
- [ ] **Лето 2028:** PyTorch, серьёзный pet-проект с нейросетью, первая стажировка или отбор на неё.
- [ ] **Лето 2029:** реальный опыт работы в команде, понятна своя ниша в ML.

Если этап идёт медленнее — план сдвигается, но порядок сохраняется: каждый этап опирается на предыдущий.
